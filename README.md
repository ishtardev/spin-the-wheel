# Spin the Wheel

A simple interactive prize wheel application.

## Description

- **HTML**: Creates the structure with a canvas element for the wheel, a spin button, and a result display panel
- **CSS**: Handles styling of the wheel, buttons, and the slide-in result panel
- **JavaScript**: Powers the wheel animation, prize selection logic, and sound effects

## Customization

You can easily customize this project by:

- Editing the `slices` array in `script.js` to change prize names
- Modifying the `colors` array in `script.js` to use different wheel colors
- Adjusting CSS properties in `style.css` to change the visual appearance
- Tweaking the animation speed parameters in the JavaScript code
